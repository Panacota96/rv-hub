Limitations

  • The RSMF files reproduce the export as delivered, not the phone or account: messages deleted before the export, unexported media and edit history are not in them.
  • rv-rsmf converts; it does not authenticate. A chat export is a text or JSON file that can be edited before it reaches the examiner; corroborate it with a forensic extraction or the other party's copy.
  • Files are checked against the published RSMF 2.0 schema and read back; how a given Relativity version displays them was not tested by this run.
  • Reactions are mapped with a fixed table of Relativity emoji shortcodes (checked 2026-10-27); other reactions are kept as text.
  • Type detection uses a limited table of common file signatures; unknown types are reported as unknown, not as suspicious.
  • Modification times come from the file system of the examined copy and may differ from the original source.
  • A result without findings does not prove that a file is authentic or unaltered before acquisition.
  • A trusted timestamp proves the audit log existed in this exact form at the stated time; it does not prove that the examined copy matches the original source.
